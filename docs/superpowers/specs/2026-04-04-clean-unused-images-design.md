# 清理未使用图片功能设计文档 (2026-04-04)

本文档概述了清理 Supabase 存储桶中未使用图片的方案。

## 1. 目标
- 找出存储在 Supabase `craft-images` 存储桶中，但没有任何数据库引用的图片。
- 删除这些无用图片以节省存储空间。

## 2. 扫描与匹配策略

### 2.1 数据库引用源 (Source of Truth)
我们需要收集以下表中引用的所有图片 URL：
- `brand_info` 表中的 `logo`, `author_wechat_qr`, `author_xhs_qr`。
- `series` 表中的 `cover_image`。
- `products` 表中的 `images` (数组)。

### 2.2 存储桶扫描
- 遍历 `craft-images` 存储桶中的所有文件。

### 2.3 匹配逻辑
- 从 URL 中提取文件名。
- 对比数据库引用的文件名列表和存储桶中的文件列表。
- 只有完全没有在上述任何表中出现的图片才被标记为“未使用”。

## 3. 安全保护
- **备份建议**：在执行删除之前，建议用户在控制台手动备份。
- **确认机制**：脚本会先输出一个详细的待删除列表，并告知图片数量。
- **软删除模拟**：先以列表形式展示，只有在用户确认后才执行 `storage.remove`。

## 4. 流程步骤
1.  **编写脚本**: 创建一个临时脚本 `scripts/clean-images.ts`。
2.  **执行扫描**: 运行脚本，输出待删除图片列表。
3.  **用户确认**: 确认列表无误。
4.  **执行删除**: 运行脚本中的删除逻辑。

## 5. 验证准则
- [ ] 脚本正确找出了未引用的图片。
- [ ] 正在被引用的图片（如系列封面）绝对不会被误删。
- [ ] 存储桶中的文件数量在删除后相应减少。
- [ ] 网站所有页面（系列详情、个人主页）的图片依然能正常显示。
